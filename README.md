# Каталог товаров (Frontend + Express API)

Небольшой учебный проект с витриной товаров и админкой для CRUD-операций.

- `index.html` — клиентская витрина (карточки товаров).
- `admin.html` — админ-панель (добавление, редактирование, удаление товаров).
- `server.js` — Express-сервер: отдает статику и REST API.
- `input.scss` / `output.css` — стили для витрины.

## Возможности

- Просмотр списка товаров на витрине.
- Добавление товара через админку.
- Редактирование товара (название, цена, фото, описание).
- Удаление товара.
- Валидация входных данных на сервере.
- CORS-настройка для запуска HTML через Live Server.

## Технологии

- Node.js
- Express 5
- HTML/CSS/SCSS
- Vanilla JavaScript (без фреймворков)

- Установленный Node.js (рекомендуется актуальная LTS-версия).

## Установка и запуск

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Запустить сервер:

   ```bash
   npm start
   ```

   или в Windows:

   ```bat
   start.bat
   ```

3. Открыть в браузере:

- Витрина: `http://localhost:3000/index.html`
- Админка: `http://localhost:3000/admin.html`
- API: `http://localhost:3000/api/products`

## Как это работает

- Сервер хранит товары в памяти (`products` в `server.js`).
- При перезапуске сервера данные сбрасываются к начальному набору.
- `index.html` запрашивает список товаров и рендерит карточки.
- `admin.html` выполняет CRUD-запросы к API и обновляет таблицу.

## REST API

Базовый путь: `/api/products`

### `GET /api/products`

Возвращает список всех товаров.

### `GET /api/products/:id`

Возвращает товар по `id`.

### `POST /api/products`

Создает товар.

Пример тела запроса:

```json
{
  "name": "Кепка Classic",
  "cost": 990,
  "image": "https://example.com/cap.jpg",
  "description": "Легкая базовая кепка"
}
```

### `PUT /api/products/:id`

Обновляет поля товара (частичное обновление).

### `DELETE /api/products/:id`

Удаляет товар по `id`.

## Валидация данных

- `name` — обязательная непустая строка.
- `cost` — неотрицательное число.
- `image` — строка URL (если передана).
- `description` — строка (если передана).

## Особенности Live Server

Если открывать `index.html` или `admin.html` через Live Server (обычно порт `5500/5501`):

- frontend будет обращаться к API по `http://<host>:3000`;
- Express-сервер должен быть запущен отдельно;
- при открытии страницы по `https://` браузер может блокировать запросы к `http://` (mixed content). Используйте `http://` или открывайте страницы напрямую через Express на `localhost:3000`.

## Полезные команды

- `npm start` — запуск Express-сервера.

## Ограничения текущей версии

- Нет постоянного хранилища (БД/файла) — данные только в памяти.
- Нет авторизации в админке.
- Нет автоматической сборки SCSS (в репозитории уже есть готовый `output.css`).
